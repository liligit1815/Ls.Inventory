# 快捷出入库与近日记录整合

调研日期：2026-09-23。面向单店日常记库存，核心流程是“看见商品 → 记一笔 → 看见结果”。

## 同类产品参考

| 官方来源 | 可借鉴的做法 | 本项目的选择 |
| --- | --- | --- |
| [金蝶进销存](https://www.jdy.com/domain/invoicing/) | 商品多维模糊搜索、快速开单、跨单据复制，减少重复填写 | 保留名称、规格、备注搜索；从近日记录带入商品，数量重新填写 |
| [Sortly 使用指南](https://help.sortly.com/sortly-mobile-app) | 商品搜索与快捷数量操作相结合，确认收货后更新库存 | 在商品旁提供入库、出库，录入时展示库存变化，完成后刷新概览 |
| [Zoho Inventory 活动报表](https://www.zoho.com/us/inventory/help/reports/activity-reports.html) | 按日期范围查看操作记录和上下文 | 保留日期及商品筛选，补充今天、近7天、近30天快捷范围 |

以上是对公开官方资料的归纳，没有登录这些产品进行完整体验。右侧录入面板是结合本项目现有页面做出的设计选择，不是对某个产品界面的复制。

## 交互选择

将全局“记入库 / 记出库”放在近日出入库标题旁。日历和每日卡片仅展示日期、商品数及入库/出库笔数，采用统一高度；选中日期后，下方共享商品明细提供快捷录入，跨日表格的商品行也可录入。库存预警的“去入库”打开同一个面板。

采用右侧面板：保留原有查询位置和展示方式，让用户能在一个页面完成查看与记账。窄屏时面板占满屏宽。直接在历史单元格里改数字容易混淆历史汇总和新业务，因此历史数字仍为只读。

点击商品旁按钮时自动带入商品和方向，数量和本次备注留空；从顶部按钮进入且只筛选了一个商品时，自动选中该商品。多选时由用户明确选择。面板标明今天记账，不提供回填历史日期。

输入数量时显示当前库存及预计结存。数量须为正整数，出库超过库存、入库后溢出或商品已停用时不能提交。服务端仍对并发和库存作最终校验。

成功后保留商品及方向，清空数量和操作备注，方便连续录入。显示上一笔回执并刷新库存、预警与近日汇总。点击“查看今天记录”时主动切到今天和刚才的商品，避免原有筛选将新记录隐藏；普通刷新保留视图及筛选。

未提交内容关闭前提示；提交中及网络结果不确定时锁定本次录入。重试沿用原请求编号和内容，不创建第二笔。停用商品可查历史，但不提供新的出入库操作。

## 紧凑日期与共享明细

日历不再设置1085像素的最小宽度，七列随页面宽度适配；每个日期不展开商品，商品数量、名称或备注长度不会改变格子高度。每日卡片同样采用统一高度，不再让今天单独占整排；按日期从早到晚、从左到右、从上到下排列，与日历顺序一致。

默认选中今天，切换视图或普通刷新保留日期，切换查询范围后若原日期不在范围内则选中最新日期。空日期可正常选择并显示空状态。点击成功回执的“查看今天记录”会选中今天及刚操作的商品。

明细每页8条，切换日期或商品筛选回到第一页；后台刷新减少商品数时自动修正页码。入/出汇总统计所选日期的全部符合条件商品，不只统计当前页。不同单位分别汇总，通过“按单位查看当日汇总”展开。点击商品名称可查看完整名称、两项规格、单位、备注和当前库存。

日期使用原生按钮支持键盘选择，选中状态同时使用边框及按下状态标记，不只依靠颜色区分。长时间范围仅日期区域滚动，没有每个格子各自的滚动条。

## 范围

沿用现有记账接口、即时过账及日志机制，不增加审批、订单、批量记账或历史修改功能。日历、表格、每日汇总卡片及自定义1～367天范围继续可用。
